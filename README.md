# Neural_Networks_in_Numpy

This repo contains several Explorations of basic neural networks in plain Numpy. 

## Contents

01 Images, RGB-Layers, Pixel Values and Matrix Multiplication
02 A Simple Perceptron
03 A Adaline Implementation
04 Demonstration of the X OR Problem. Notorious as trigger of the firs AI-Winter

## Installation

if you use uv as package manager:

`uv init`  
`uv sync`

for pip users & windows

`py -m venv .venv`  
`.venv\Scripts\activate`   
`py install pyproject.toml` 

have fun ;-) and run the notebooks; improve it or send me a feedback.
